# После дождя

Браузерный пиксельный экшен-платформер, сильно упрощённый аналог Dead Cells. Герой основан на предоставленной фотографии; место действия: мрачный Батуми с коммунальным чёрным юмором.

## Согласованный стек

Решение зафиксировано 5 сентября 2026 года: **Phaser 4 + TypeScript + Vite**. Причина выбора: больше готовых игровых систем в одном движке.

- Phaser отвечает за рендеринг, сцены, загрузку ресурсов, анимации, камеры, ввод, звук, частицы и визуальные эффекты.
- Для движения и столкновений используем встроенную Arcade Physics.
- Свой код описывает игровые правила: атаки, перекат, поведение врагов, улучшения и прохождение.
- Уровни храним в файлах проекта; отдельный визуальный редактор пока не нужен.

PixiJS, Rapier и `@pixi/sound` не входят в выбранный стек. Собственный движок, физический решатель и отдельный цикл рендеринга не планируются.

## Запуск

Нужен Node.js 22.12 или новее и браузер с WebGL. Установить зависимости и запустить:

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Игра рассчитана на компьютер с клавиатурой.

```sh
npm test                 # правила боя и импорт спрайтов
npm run test:browser     # интеграционные проверки Chromium
npm run build           # готовый статический сайт в dist/
npm run preview         # проверка сборки на localhost:4173
```

Перед первым браузерным тестом: `npx playwright install chromium`. Папку `dist` можно разместить на обычном статическом хостинге, в том числе в подпапке. Бэкенд, аккаунты и API-ключи для игры не нужны. Запуск через двойной щелчок по HTML (`file://`) не поддерживается; нужен HTTP-сервер.

Структура запуска и конфигурации адаптирована из официального [Phaser Vite/TypeScript template](https://github.com/phaserjs/template-vite-ts), MIT. Отдельный пример платформера не копировался: движение использует готовую Arcade Physics, а игровые правила написаны для этого проекта.

## Версия 0.6 — спокойнее темп, точнее управление

Играбельный прототип: старые дворы → бетонный район → ночной порт. Герой по фотографии, двойной прыжок, комбинация ударов, неуязвимый рывок, две аптечки, тайники с выбором улучшения, три типа врагов и Старший по порту с усиленной второй фазой. Убери всех противников участка и нажми E у ворот. После порта откроется экран победы и повторный забег.

Бой состоит из замаха, контакта и восстановления. Нажимай J повторно во время завершения текущего удара, чтобы связать три удара. Очередь хранит одно нажатие до 240 мс игрового времени; повторное нажатие обновляет её, отмена рывком очищает. Короткие нажатия сохраняются между кадрами, удержание J не включает автоматическую атаку. Оружие одно — труба. Все три удара направлены перед героем: первые два наносят по 16 урона, третий — 32 и дольше восстанавливается. Улучшение урона сохраняет пропорцию 1–1–2. Поворот между ударами возможен по намерению игрока, автоматического обратного удара нет. Готовый рывок отменяет удар, в том числе во время hitstop. R больше не используется.

Длительность ударов без hitstop: 420 / 460 / 620 мс. Полнотелый замах переходит в короткий контакт и постепенное завершение. Автоматического продвижения от удара больше нет: обычное движение — 150 пикселей/с, во время атаки — 90 и только пока держишь направление. Отпускание и разворот сразу меняют требуемую скорость, без разгона и скольжения. Рывок стал спокойнее: 380 пикселей/с на 180 мс. Камера быстрее останавливается вслед за героем. Пиксельный шлейф показывает траекторию даже при промахе, вспышка и частицы появляются в точке контакта. Стоп-кадр 50 / 55 / 85 мс применяется один раз на взмах, независимо от числа целей. Первые удары слегка отталкивают, третий сильнее. Звук взмаха, обычного попадания, тяжёлого попадания и добивания имеет по три оригинальных варианта.

F создаёт короткий видимый пинок перед героем. Он толкает и прерывает обычного противника, но не бронированную атаку босса, затем восстанавливается 1,7 секунды. Q запускает лечение на 0,75 секунды: движение, прыжок, атака, рывок, пинок или полученный урон прерывают канал, не расходуя аптечку. Только завершённое лечение даёт 35 здоровья и тратит одну аптечку.

E у тайника открывает небольшой выбор: 1 даёт урон +6, 2 даёт максимальное здоровье +20; оба варианта восстанавливают одну аптечку. Выбор применяется один раз, сохраняется при переходе между районами и сбрасывается новым забегом. Escape позволяет отойти без расходования тайника.

Противники готовят каждую атаку четырьмя разными полнотелыми позами; у босса отдельные последовательности подъёма якоря и залпа. Добитый враг сразу выходит из боя, но успевает осесть в короткой анимации. Падение, исчезновение и наземные брызги замораживаются на паузе. Локальная вспышка стала компактнее, числа урона приподняты, тряска слабее. Тень остаётся на реальной поверхности при прыжке; редкие брызги отмечают шаги и приземление.

Первый двор получил проходы под аркадами, навесы, балконы и крышу с отдельным противником. Верхний маршрут даёт доступ к улучшениям. Камера ближе, у персонажей тонкая контрастная обводка. Чёрный юмор касается городского быта, аренды и бюрократии, а не национальности жителей.

Внешность героя сохранена по референсу: волосы, очки, борода, чёрная одежда. Число тайников и баланс ещё можно настраивать. Исходная цель 5–10 минут остаётся ориентиром для первого знакомства, а не измеренной гарантией длительности. Это прототип, не законченная коммерческая игра.

### Управление

| Действие | Клавиши |
| --- | --- |
| Движение | A / D или ← / → |
| Двойной прыжок | Пробел, W или ↑ |
| Удар / продолжение комбо | J или левая кнопка мыши по игровому полю |
| Пинок / прерывание обычного врага | F |
| Рывок / отмена удара | Shift или K |
| Тайник / переход | E; выбор в тайнике 1 / 2, отмена Escape |
| Лечение 0,75 секунды | Q |
| Пауза / продолжение | Esc |
| Звук | M или кнопка в шапке |

Игра ставится на паузу при потере фокуса. Звук включается после взаимодействия с игрой, его настройка сохраняется локально, когда браузер разрешает хранилище. Тряску камеры можно отключить. Сенсорное управление, геймпады, процедурная генерация и сохранение забега не входят в эту версию.

## Ресурсы

Весь арт и звук находятся в `public/assets`, запросов к сервисам генерации во время игры нет. Происхождение ассетов и промпты: [ASSETS.md](ASSETS.md). Лицензия стартового шаблона: [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).

В версии 0.6 атласы содержат 160 полнотелых кадров: 64 у героя, 64 у обычных врагов и 32 у босса. Некоторые старые позы сохранены для совместимости индексов, но заменены в текущих анимациях. Труба имеет 8 поз на каждый удар; обычные враги — 4 отдельные позы отдачи. Каждая атака врага имеет 4 позы подготовки, 2 контакта и 2 восстановления; добивание — ещё 4 позы на тип врага. Стойка и бег держат трубу в руках; атаки, пинок, перекат, прыжок, приземление, лечение, реакция на урон и смерть имеют собственные позы. При загрузке цветовой ключ становится прозрачным, силуэты выделяются независимо (оружие не обрезается границей исходной сетки), кадры укладываются в атласы с общей регистрацией ног. Размеры физических тел героя сохранены. Точки контакта трубы и ноги размечены на исходных пикселях и преобразуются вместе со спрайтом; нанесение урона управляется фазой атаки, а не независимым таймером анимации. Руки/оружие больше не дорисовываются поверх персонажей линиями. Архитектура, тайники и ворота рисуются средствами Phaser. Это подготовка текстур, не отдельный рендерер. Phaser отвечает за дальнейшее отображение и анимацию.
