# Art and audio provenance

All final assets are local in `public/assets`. Generated using the built-in imagegen tool, 2026-09-05 and 2026-09-06. The supplied personal photograph is a reference only, never included in the web build. Generated art is not claimed to be third-party stock or licensed Dead Cells content.

| Asset | Role | Import |
| --- | --- | --- |
| `public/assets/batumi.png` | Generated gloomy Georgian city panorama | Phaser parallax scenery and title backdrop |
| `public/assets/hero-source.png` | Generated photo-referenced 8-pose sprite sheet | Chroma-key import, 4×2 source to 8 aligned 64×80 frames |
| `public/assets/enemy-source.png` | Generated walker, spitter, hound, port guardian | Chroma-key import, actor textures |
| `public/assets/audio/*.wav` | Original procedural effects and rainy drone | Phaser Sound; generated by scripts/generate-audio.mjs |

Graphics shapes, platforms, lamps, clotheslines, signs, particles and fallback silhouettes are project-authored Phaser graphics. Font stack uses installed system fonts; no remote fonts.

Version 0.2 retains the generated sources unchanged. `src/game/architecture.ts` supplies original code-native arcade facades, supported balconies, shop signs, rooftop equipment and weathering. Small cache/gate textures are authored Phaser pixel rectangles in `src/game/art.ts`. Actor rims are a one-pixel runtime alpha-import operation, independently applied within each hero frame to prevent bleeding between frames.

## Prompts

### City

Use case: stylized-concept. Asset type: final production environment background for a 2D pixel-art side scrolling action game, dark coastal Batumi in Georgia at blue hour in the rain.
A very wide cinematic side-view panorama of an eerie empty Georgian coastal city. Old plaster buildings with intricate dark wooden Georgian balconies, wall-mounted air conditioners, exterior pipes, sagging electrical wires, narrow worn staircases, Soviet concrete apartment blocks farther away, wet coastal mist, the suggestion of Batumi's modern towers and port cranes in the distance. One warm amber-lit corner grocery and a tiny desaturated red pharmacy cross. Fine rain, a few warm windows, muted mint reflections against deep petroleum-blue shadows, overcast smoky sky. No medieval architecture, no pagodas, no cyberpunk skyscraper neon extravaganza. Ordinary contemporary Batumi made atmospheric, beautiful and melancholy.
Handcrafted premium indie-game pixel art, a genuine crisp low-resolution 640x360 style enlarged with nearest neighbor, square pixel clusters and dithering, detailed architectural silhouettes, carefully limited colors, no smooth digital painting. Wide landscape 16:9 composition 1536x864 or equivalent. Static 2D orthographic SIDE VIEW for a platformer, no perspective vanishing-point street. Buildings fill middle and far background. The bottom fifth is dark, unobtrusive sidewalk with wet pavement, a readable continuous horizontal ground line; gameplay objects will be drawn over this separately. No characters, no cars in the foreground, no enemies, no UI, no text, no logos, no watermark. Enough contrast to read the architecture in a dark game.

### Hero source

Use case: stylized-concept. Asset type: production pixel-art character sprite sheet for a side-scrolling action platformer.
Image 1 is ONLY a reference for the identity of the protagonist. Recreate this same man recognizably as crisp hand-crafted 32-bit pixel art: tousled medium-length dark brown hair sweeping across forehead, prominent black rectangular eyeglasses with tiny pale lens reflections, short dark beard, light skin, black crew-neck sweatshirt, black trousers, dark sneakers. No cape, no armor, no hat. Modest realistic body proportions, slightly enlarged head for readable face.
Create a transparent PNG sprite sheet, exactly 4 columns and 2 rows, equal-sized cells, no outlines of cells, no labels, no text. Overall image 1024 by 1024, each cell 256 by 512. Every character is full body, same size, aligned on identical ground baseline y=448 within its own cell, head near y=100, horizontal center x=128. Generous transparent gutters. All face RIGHT in a three-quarter side view, as used in a 2D platformer.
Frames reading left to right: top row 1 idle stance, 2 idle breathing variation, 3 run pose leading right leg, 4 run passing pose. Bottom row 5 run pose leading left leg, 6 run passing opposite pose, 7 airborne jumping tucked legs, 8 sword attack stance with one extended right arm (do not draw a weapon, weapon rendered by game). Each cell has ONLY one instance of the same character, exactly eight characters total.
Pixel art with visible square pixel clusters, limited charcoal / desaturated indigo cloth palette, warm light skin, fine cool rim light to separate black clothing from a dark city. Hard edges, no antialiasing, no painterly texture. Genuinely transparent background, no white background, no checkerboard drawn into image, no ground shadows, no environment. Preserve resemblance to reference photo in every frame.

Refinement: preserve eight characters in their cells, four columns and two rows; remove background. The tool returned a baked checkerboard instead of alpha. A subsequent built-in edit replaced only the background with solid RGB(255,0,255) for standard game sprite import. No original photo is loaded at runtime.

### Enemy source

Four original enemies in a single row on solid magenta: soaked supernatural worker in petrol coat; hooded spitter in desaturated plum; asphalt stray hound; imposing dock foreman in teal raincoat and brass helmet carrying an anchor. Crisp 16-bit pixel clusters, grey/moss/rust/amber palette, no UI or text. Source enemies face left; imported textures are normalized to face right for actor-facing rules.

## Validation

Runtime import removes the color key (including edge fringe), keeps facial and clothing details, uses nearest-neighbor scaling, and aligns hero feet to frame y=77. Raw source files intentionally retain the color-key background. Assets can be regenerated without online dependencies in the game itself; new AI generation is an authoring task only.

Created with the built-in imagegen tool, using the existing photo-derived hero and enemy art as identity references. Original sheets are preserved; the photograph is not shipped. Standard deterministic import: chroma key, connected-component slicing, nearest-neighbor resizing, foot/root registration, one-pixel rim, frame packing. This does not generate or redraw limbs. The boss source's left-facing idle/slam frames are flipped during import, while its right-facing cast frames are retained. Isolated background motes are omitted; normal game particles handle impacts and projectiles.

Hero atlas: 1536×720, 40 frames of 192×144, feet at (96,128). Hero scale and origin preserve the old 20.625×41.25-world-pixel Arcade body. Enemy/boss atlases use 128×128 frames, feet at (64,112). Source-pixel hand/tip/boot contacts and per-pose anchors live in `src/game/spriteFrames.ts`. No per-frame normalization that would enlarge a crouching head. Runtime requires no AI service.
